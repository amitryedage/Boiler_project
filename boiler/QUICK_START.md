# BoilerGuard Dashboard - Quick Start Guide

## 🚀 Launch the Dashboard

Simply open `index.html` in your web browser. That's it!

## 🎮 Interactive Features Guide

### 1️⃣ Real-Time Data
The dashboard automatically updates every 2-3 seconds:
- ✅ KPI values change dynamically
- ✅ Gauge needles move smoothly
- ✅ Charts add new data points
- ✅ Health score updates

### 2️⃣ Click Anywhere!
**Everything is interactive:**

#### KPI Cards (Top Row)
- Click **Efficiency** → View 24-hour efficiency trend
- Click **Risk Index** → See risk assessment details
- Click **Blowdown Rate** → Check optimization history
- Click **Savings** → View cost savings breakdown

#### Gauge Meters
- Click **pH** → Detailed pH monitoring
- Click **TDS** → Total dissolved solids analysis
- Click **Turbidity** → Water clarity metrics
- Click **Temperature** → Thermal monitoring
- Click **Pressure** → Pressure trend analysis

#### Top Navigation
- Click **Plant Selector** → Switch between boiler plants
- Click **🔔 Bell Icon** → View notifications (2 new alerts)
- Click **⚙️ Settings** → Export data, print, fullscreen
- Click **Profile** → Access user menu

#### Action Buttons (Right Panel)
- Click **Initiate Surface Blowdown** → Start blowdown process
- Click **Confirm Action** → Confirm the operation
- Click **Call Engineer** → Alert engineering team
- Click **Dismiss** → Close the alert

### 3️⃣ Control Panel (Bottom Right)
- **⏸️ Pause Button** → Stop real-time updates
- **▶️ Play Button** → Resume updates
- **🔄 Refresh** → Force data refresh
- **🟢 LIVE** → Shows current status

### 4️⃣ Theme Toggle
- Click **☀️/🌙 Icon** (top right) → Switch dark/light mode
- Or press **Ctrl+K** (Windows) / **Cmd+K** (Mac)

### 5️⃣ Keyboard Shortcuts
- `Ctrl/Cmd + K` → Toggle theme
- `ESC` → Close any open modal

## 🎯 Try These Actions

1. **Pause the Dashboard**
   - Click pause button (bottom right)
   - Notice "LIVE" changes to "PAUSED"
   - Data stops updating

2. **View Detailed Metrics**
   - Click any gauge card
   - See detailed modal with trends
   - Press ESC to close

3. **Switch Plants**
   - Click "Boiler 2 - Textile Plant"
   - Select different plant
   - See confirmation notification

4. **Check Notifications**
   - Click bell icon (shows "2")
   - View foaming risk alert
   - Click notification to mark as read

5. **Take Action on Alert**
   - Click "Initiate Surface Blowdown"
   - Watch button change to "Processing..."
   - See success notification

6. **Export Data**
   - Click settings icon (⚙️)
   - Select "Export Data"
   - JSON file downloads automatically

7. **Toggle Theme**
   - Press Ctrl+K or click theme button
   - Watch smooth transition
   - Theme saves automatically

## 🔧 Troubleshooting

### Charts not showing?
- Check internet connection (Chart.js loads from CDN)
- Refresh the page

### Theme not saving?
- Check browser localStorage is enabled
- Try clearing cache

### Animations laggy?
- Close other browser tabs
- Pause real-time updates

## 💡 Pro Tips

1. **Pause for Screenshots**: Use pause button before taking screenshots
2. **Fullscreen Mode**: Press F11 or use settings menu
3. **Print Dashboard**: Use settings → Print for reports
4. **Export Data**: Regular exports for record keeping
5. **Keyboard Navigation**: Use Tab to navigate, Enter to click
